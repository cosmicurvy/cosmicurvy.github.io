I learn by building

I taught myself data science, and every project on this page started with a real question and ended with something you can run, read or click.

I care about the full path from raw data to a working tool, not only the model score.

  1. Explore and clean

    Start with the question, then check the data for gaps and class imbalance before choosing a model.

  2. Model and explain

    Compare approaches, validate with cross-validation, and explain predictions with SHAP where it helps.

  3. Ship and document

    Wrap the model in a Streamlit, Flask or FastAPI app, containerize it with Docker, and publish the code on GitHub.
